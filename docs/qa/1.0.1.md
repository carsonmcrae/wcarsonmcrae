# Daysforth 1.0.1 visual and interaction review

Reviewed November 5, 2026 in the Windows in-app Chromium browser at its normal desktop width and a
390 CSS-pixel viewport. This is a browser/keyboard review, not a native iPhone or screen-reader test.
The [implementation record](../V1.0.1-RELEASE.md) keeps every follow-up request in scope.

The profile uses quiet outlined handle, Nashville, TN and destination chips. All remain available
on narrow layouts. Category metadata uses readable Work/Projects/Life color/icon chips, matching
filter icons, with the existing separate milestone treatment. The timeline begins without edge
arrows above the profile and pins; its oldest end exposes the useful upward direction after scrolling.

The footer was compared with Carson’s selected third mock and explicit revisions: one top divider,
Daysforth/signature, visible Privacy/Settings/Accessibility/Releases, remaining destinations in More,
and quiet copyright/update text. Desktop More opens upward. Phone More expands in normal flow so
it does not cover adjacent controls. The separate first-visit banner is unchanged; choosing Keep
storage off removed it. Settings opened the existing dialog, and Escape returned focus to Settings.

Each dog card retains its portrait and breed details and has a compact eight-photo album entry.
About retains its introductory portrait; its eight-photo preview follows Quick facts. Visible
thumbnails have no caption/link blocks below them. The opened viewer shows a caption, count,
previous/next controls and a related moment where supplied. Next and ArrowLeft changed the photo
and count correctly. Scrolling with the viewer open left background scrollY at exactly 1434;
Escape restored the original “View Margot’s photos” trigger at that same position.

The desktop moment rail sits in the scrollbar gutter. Opening its keyboard preview kept scrollY
at exactly 4566. Home/arrow navigation reached the TTSNative entry among several October 2026
events; Enter focused its title and placed its card below the sticky dock (card top 247.66, dock
bottom 219 CSS pixels), then closed the preview. Automated checks separately cover pointer hover,
touch reveal, 1920px edge placement, category changes and collapsed date groups.

The Contact location sentence is removed. Pickleball uses the approved ping-pong caption and no
longer compares itself to golf. Standalone video links have a local YouTube glyph and preserve
their isolated new-tab behavior without loading an embedded player.

Final automated counts, scanner results, source/tag identities, deployment and live acceptance
are recorded in the release pull request. Fresh NVDA remains off at Carson’s request; VoiceOver on
macOS/iOS is unavailable on this Windows machine. Automated WebKit/axe and this review do not
establish full accessibility conformance.
