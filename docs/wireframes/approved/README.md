# Approved Daysforth visual reference

Carson approved these layouts on November 4, 2026. They are the visual target for the implementation,
with these explicit changes:

- Replace the working name Thenroll with Daysforth and its new identity.
- Use Carson’s approved real photographs and existing project artwork.
- Give event metadata, titles, captions, and actions distinct line heights and comfortable gaps.
- Remove the “Drag to explore” hint.
- Label the overview rail only at November 1999, May 2022, and October 2026. Place the labels by
  elapsed time; stagger them on narrow screens.
- Require a month and year for every moment, with day precision optional.

The images contain generated sample photography. Those people are illustrative, not Carson or his
family. Production photographs live in `src/assets/photos/`.

`timeline-desktop.png` and `posts-desktop.png` show the two modes. `timeline-mobile.png` shows mobile
composition. `controls-and-menus.png` defines the consolidated controls.

The older HTML wireframes one directory above are superseded for visual design.
