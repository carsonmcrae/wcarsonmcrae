# Daysforth 1.0.1 implementation record

This release keeps the complete follow-up scope together. Visitor-facing notes live at
`/releases/1.0.1/`; final checks, source identities, deployment and live acceptance belong in the
release pull request. Architecture ownership is maintained in [the overview](architecture/overview.md).

| Request                 | Result                                                                                                                                                                                                                                                                            |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Timeline edge arrows    | Hidden over the profile and pins; actual scrolling into the feed qualifies them. Hide the direction whose end is already visible, and hide both outside the story.                                                                                                                |
| Category presentation   | Work, Projects and Life share readable color/icon chips across cards, permanent posts and filter choices. The selected filter uses the same glyph. Milestones remain distinct.                                                                                                    |
| Profile chips           | The handle, Nashville, TN and all four profile destinations use restrained outlined chips, with readable wrapping on mobile.                                                                                                                                                      |
| Photo controls          | Small count and post affordances straddle the photograph’s upper corners and reveal on event hover, keyboard focus or deliberate touch. Titles and ordinary links retain their direct behavior.                                                                                   |
| Dog albums              | Each existing dog card retains its main photograph and breed details and leads into a compact preview. Both original photographs and six additional photographs form each eight-photo carousel.                                                                                   |
| About photos            | The main portrait stays in the introduction; the eight-photo album preview moves below Quick facts.                                                                                                                                                                               |
| Carousel behavior       | Previous/next buttons, arrow keys and deliberate horizontal swipes traverse complete albums without autoplay. Captions and related moments appear inside the viewer. Closing restores the original trigger and background position. Native image links remain without JavaScript. |
| Desktop event navigator | A compact rail beside the scrollbar previews the currently filtered timeline and jumps to the exact event, including several events sharing a month. Narrow screens retain existing browsing controls.                                                                            |
| Video destinations      | Standalone YouTube links have the platform’s play glyph, preserve their explanatory wording and open isolated new tabs. No player or remote media loads on page view.                                                                                                             |
| Approved footer         | One top divider and compact identity/action flow. Privacy, Settings, Accessibility and Releases remain visible; Timeline, Work, Life, About, Contact, Brand kit and Source move into More. Legal copy and update date remain.                                                     |
| Storage banner          | The existing separate first-visit banner remains and disappears after either choice. The footer redesign does not change consent or persistence.                                                                                                                                  |
| Contact copy            | Removed the redundant Nashville sentence below conversation topics.                                                                                                                                                                                                               |
| Pickleball copy         | Replaced the golf comparison with the approved full-court ping-pong line and removed the comparison from the body.                                                                                                                                                                |
| Versioning              | Package/lockfile version and permanent release history advance to 1.0.1; the 1.0.0 record remains available.                                                                                                                                                                      |

The footer follows the selected revised mock on desktop. On phones, an opened More menu expands
in normal flow so it does not cover nearby Settings or Accessibility targets; its closed state
stays compact. The transient consent banner remains separate by Carson’s explicit instruction.

No original photographs, Worker bindings, reaction keys, schema, aggregate counts, consent data or
provider configuration change in this release. There is no new external service or visitor storage.
Per-file coverage, duplication, dependency boundaries, size budgets and release gates remain intact.

Manual browser/keyboard results and unavailable assistive-technology checks are recorded in
[design QA](../design-qa.md). Automated checks and scanner results are evidence, not a certification
of full accessibility conformance or the absence of every possible vulnerability.
