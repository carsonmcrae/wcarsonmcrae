# Contributing a fix

Bug reports, accessibility improvements, security fixes, and focused patches for Carson’s
Daysforth website are welcome. This is a public, source-available personal project with restricted
reuse, not a general-purpose open-source template. Read [LICENSE.md](LICENSE.md) and [AGENTS.md](AGENTS.md).

1. Open a focused issue or fork a branch for a patch. Use private vulnerability reporting for
   security issues; follow [SECURITY.md](SECURITY.md).
2. Keep personal content factual, public-safe, and approved by Carson. Do not add tracking,
   credentials, unapproved photos, dependencies, or unrelated product features.
3. Add meaningful focused tests. Follow the repository’s architecture, accessibility, coverage,
   duplication, line-limit, and ownership gates.
4. Run the complete validation once the patch is ready. Explain behavior, verification, and any
   checks you could not perform. Only Carson authorizes the final merge and deployment.

Submit only work you have the right to contribute. By submitting a contribution, you grant William
Carson McRae permission to use, modify, publish, and distribute it as part of Daysforth under this
project’s terms. You retain your rights in your original contribution. This permission does not
relicense unrelated third-party material or grant permission to reuse Daysforth elsewhere.
